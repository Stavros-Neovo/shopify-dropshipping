📋 Was passiert bei einer Retoure?
1. KÄUFER MELDET
Käufer öffnet Retourenantrag auf eBay (14–30 Tage nach Erhalt)
2. RETOURE ANNEHMEN
Innerhalb 3 Tagen reagieren. Retoure akzeptieren → Retourenlabel erstellen
3. WARE PRÜFEN
Artikel von BAB zurückschicken? Oder neu verkaufen? Schadensbewertung
4. ERSTATTUNG
eBay erstattet dem Käufer. eBay-Gebühren werden teils zurückgebucht (nicht immer)
💡 Tipp Dropshipping: Bei defekter Ware sofort BAB kontaktieren (SSchulze@bab-distribution.de) — BAB übernimmt in den meisten Fällen die Rücknahme oder schickt Ersatz. Dein Verlustrisiko ist damit minimal.
